# BLOG · 记录与分享

???**v0.261115** ? ???????? ? [GPLv3 ??](LICENSE) ? [????](COPYRIGHT.md)

独立 Python 博客社区，采用 Flask、Jinja2、SQLite 和 Waitress。界面为现代浅色卡片风格，支持桌面与手机访问，不依赖外部字体或 CDN。

## 功能

- 访客浏览、全文关键词搜索、分类筛选和分页。
- 用户注册、登录、退出及修改密码；密码使用加盐哈希存储。
- Markdown 发文、编辑、删除、草稿与公开发布。
- 作者可在编辑页取消“允许评论”，保存后立即禁止新增评论，已有评论保留；重新勾选即可恢复。
- 已登录用户发表评论；评论作者、文章作者和管理员可以删除评论。
- 后台管理文章、评论与用户；管理员可停用用户、分配管理权限和重置其他用户密码。
- 草稿仅作者与管理员可见；所有写入操作均验证 CSRF。

## 启动

Windows 双击 `start.bat`，或在 PowerShell 中执行：

```powershell
cd C:\20260501\qionghai\BLOG
.\start.ps1
```

首次启动脚本会创建独立 `.venv` 并安装依赖。默认监听 `0.0.0.0:8700`，浏览器打开 http://127.0.0.1:8700 。局域网访问使用运行主机的 IP 与相同端口。

Linux / Ubuntu：

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python app.py
```

初次初始化自动创建 `admin` 管理员。初始密码从环境变量 `BLOG_ADMIN_PASSWORD` 读取；未设置时随机生成。实际初始化凭据保存在 `data/initial-admin.txt`，登录后可在右上角账户设置修改。此文件仅记录初始密码，修改密码后不会自动更新。

可选环境变量：`BLOG_HOST`（默认 `0.0.0.0`）、`BLOG_PORT`（默认 `8700`）、`BLOG_SECRET_KEY`（未设置时自动生成并保存在 `data/.secret`）。`BLOG_ADMIN_PASSWORD` 只作用于首次创建管理员，不会覆盖已有账户。

## 使用

管理员可进入“管理后台 → 平台设置（LOGO / 名称）”，修改平台名称、上传或更换 LOGO，点击保存后统一应用于页头、页脚和浏览器标题。名称最多 40 字；LOGO 支持 PNG、JPG、WebP、GIF，最大 5MB，GIF 保留首帧。勾选“恢复默认图标”可移除自定义 LOGO。设置保存在 SQLite 的 `settings` 表，LOGO 文件存放于 `data/images`。

1. 点击“加入社区”注册，再登录。
2. 点击“写文章”，填写标题、分类及 Markdown 正文，保存后可查看文章。
3. 取消“公开发布”可保存为草稿；“我的文章”可继续编辑。
4. 取消“允许评论”可关闭这篇文章的新增评论。
5. 管理员登录后点击“管理后台”，进入文章、用户、评论管理页；用户重置密码操作位于“用户管理”。

当前邮箱用于账户登记，不包含邮件验证及邮件找回密码服务；忘记密码可由管理员重置。

### 多格式文章内容

编辑页“选择文件”支持 `.md`、`.markdown`、`.json`、`.txt`、`.utf8`、Word `.docx`。导入仅替换编辑器正文，点击“保存文章”才写入数据库；已有正文时会提示确认替换。未填写标题时自动使用文件名。

- Markdown 保留语法，阅读页显示排版效果。
- JSON 自动校验并格式化，阅读页按代码文本显示。
- TXT / UTF8 文件采用 UTF-8（兼容 BOM）编码，保留换行，按纯文本展示。
- Word DOCX 转换为可编辑 Markdown，保留文字及基本结构，不保留图片或复杂版式。旧版 DOC 请先另存为 DOCX。
- 支持手动选择正文格式、直接粘贴编辑，以及保存前“预览正文”。

每个导入文件最多 1MB，转换后正文最多 10 万字；不保存上传原件。

### 图片与富文本

评论支持点击“表情”插入常用 Emoji，也可通过“图片表情包”上传或粘贴图片。每条评论最多 3 张，每张最多 5MB，支持 JPG、PNG、WebP、GIF（GIF 保留首帧）；可以只发表图片表情包。发表前可移除已选图片。评论关闭后同样不能发表表情包；评论删除权限与文字评论一致。

新文章默认使用富文本编辑器，可设置标题、加粗、斜体、下划线、字号、文字颜色、对齐、列表、链接和表格，支持全屏编辑、撤销与重做。已有 Markdown、JSON、TXT 文章保留原格式，可在正文格式下拉框切换。

“插入图片”可选择一张或多张图片；富文本编辑器也支持直接粘贴或拖入图片。Markdown 模式插入图片时生成相对路径语法。单张图片最大 5MB，支持 JPG、PNG、WebP、GIF；服务器验证实际图片内容，缩放至最长边 2560 像素并转为 WebP，GIF 仅保留首帧。图片存放在 `data/images`，随整个 `data` 目录一起备份。

图片使用随机地址公开提供访问，不适合存储私密附件；删除文章不会自动清理图片，以免误删被其他文章引用的图片。富文本保存、预览和展示时均过滤危险 HTML；外部图片需下载后通过本系统上传。编辑器依赖的 Summernote 和 jQuery 均存储于 `static/vendor`，无需外部 CDN，许可证一并保留。

## 数据与维护

数据库：当前本地服务使用 PostgreSQL，连接配置保存在私有文件 `data/database.json`，格式为 `{"url":"postgresql://用户名:SET_LOCALLY_BEFORE_USE@主机:5432/数据库?sslmode=prefer"}`；环境变量 `BLOG_DATABASE_URL` 优先。修改后重启服务生效。不要将此文件公开发布。未配置时仍支持 SQLite（`data/blog.sqlite3`），不会自动迁移数据。

从 SQLite 迁移到新的空 PostgreSQL 数据库：先停止服务、备份 `data` 目录，配置目标连接，然后运行 `.venv\Scripts\python.exe migrate_postgres.py`。工具逐表校验内容、重置 ID 序列，目标已有数据会拒绝覆盖。PostgreSQL 数据须使用 `pg_dump` 独立备份；`data` 目录仍需备份图片和 `.secret`，仅复制原 SQLite 文件不能备份当前在线数据。

前台使用 Waitress 提供服务，不启用 Flask 调试器。公网部署建议通过反向代理提供 HTTPS，并按实际使用情况配置访问限速。使用 HTTPS 时可在应用配置中启用 `SESSION_COOKIE_SECURE`。
